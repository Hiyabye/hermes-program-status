# hermes-program-status: next steps

Check the rest of the install output for whether enabling and gateway activation succeeded. This note can appear before those steps finish. It does not mean the plugin is active yet.

Once enabled, open a new terminal in the Herdr desktop app and start `hermes -p <profile>`, using your chosen profile name (`default` for the default profile). An existing CLI session has not registered its terminal with the new plugin.

The new session should show as Hermes, idle. Send a prompt to check working, then done. Ask it to use its clarify tool to check "needs you". If your Herdr phone connection is already set up, you can answer there too.

Plugins are per profile. Change only the profiles the person chose. Do not restart a gateway or disable another plugin without approval.
